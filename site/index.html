oru

Patch Android apps on your own phone.

Oru runs patch bundles on an APK you supply, signs the result on your device and installs it.

Download the latest release Source code

How it works

  1. Choose an app or APK. Pick an app installed on this device, or select an APK file you already have.
  2. Get the version Oru asks for. Oru shows which versions the selected patch bundle supports and marks the recommended one. If you need the file, Get APK opens its APKMirror page. Oru does not download it for you.
  3. Choose patches. Simple mode uses the recommended set. Expert mode lets you pick patches and their options.
  4. Oru patches, signs and installs. Patching runs on the device. The signing key stays on this device. The app installs when your installer allows it.

A patched app is signed with a different key than the stock app, so Android does not install it over the stock app. Oru can remove the stock app first if you allow it. Removing the stock app deletes its data, so back up anything you need before you patch.

Principles

  • Your APK, your device. Oru never downloads a stock APK, and it does not store or share APK files. Get APK opens the APKMirror page in your browser. You download the file and select it in Oru.
  • Simple by default, Expert when you want control. Oru picks the sensible path. A few switches remain for people who need them, such as pre-release channels.
  • Open source under GPLv3. The source code is public on GitHub. Oru is licensed under the GNU General Public License v3.0, with the additional terms in NOTICE.

Requirements

  • Android 8.0 (API 26) or newer.
  • Shizuku is optional. When Shizuku is running, Oru can install without showing the system prompt.
  • Free storage for the APK you supply and for the patched output. Check the size of the app you want to patch first.

Independent project

Oru is a modified version of Morphe Manager, which is built on ReVanced Manager and Universal ReVanced Manager. Thanks go to the Morphe and ReVanced contributors and to the authors of every patch bundle.

Oru is not made, endorsed or supported by Morphe, ReVanced, Google or the makers of any app that Oru can patch. Patch bundles are the work of their authors. Oru does not provide, host or distribute apps, APKs or patches.

Patching an app can change how it behaves and may break it. Patching may also go against the terms of service of that app. You are responsible for the apps you patch and for the APK files you use.
