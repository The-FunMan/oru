# Knowledge base

What a new maintainer, or an agent with no memory of earlier work, needs to know about Oru that the code alone does not say.

| Page | Read it for |
| --- | --- |
| [Architecture](architecture.md) | How the app, the patcher, the Rust crates and the pipelines fit together, and where each screen lives. |
| [Product decisions](product-decisions.md) | The choices that are settled, with the reason, so they are not reopened by accident. |
| [Lessons](lessons.md) | Failures that cost time, and the check that prevents each one. |

The step-by-step procedures are the runbooks in [docs/maintainers/](../maintainers/RUNBOOK.md). The rules every change follows are in [AGENTS.md](../../AGENTS.md).

Keep these pages short and true. When a decision changes, change the page in the same pull request. Do not put personal names, addresses, device identifiers or credentials here: this repository is public.
